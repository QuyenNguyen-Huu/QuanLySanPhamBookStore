# Bookstore Management System

## 📌 Introduction
A web application built to manage bookstore operations, including products, categories, and user authentication. This project was developed as part of my Information Technology specialized course to practice **Backend Development** and **Cloud Integration**.

## 🛠 Tech Stack
* **Language:** Java 17 (Spring Boot framework).
* **Database:** MongoDB.
* **Authentication:** Google OAuth2 API.
* **Architecture:** MVC (Model-View-Controller) with Repository pattern.
* **Frontend:** HTML, Thymeleaf.
* **Build Tool:** Maven.

## 🚀 Key Features
* **Product Management:** Full CRUD (Create, Read, Update, Delete) for books and categories.
* **Advanced Search:** Filter products by name or genre.
* **Social Login:** Secure authentication using Google accounts.
* **Admin Dashboard:** Specific controllers for administrative tasks.

## 🛡️ Security Note
* Sensitive information (API Keys, Database credentials) has been removed from the source code and replaced with environment variables/placeholders for security best practices.
* Google OAuth2 secrets are managed through secure configuration listeners.
